# Screenshots

The root `README.md` has a commented-out block where these go. Capture them,
drop them in this folder, then replace that comment with:

```markdown
![MarkScope reading a document](docs/images/markscope-light.png)
```

## What to capture

Three shots, at the default window size or a little larger, with
`test-docs/` added as a root plus one real folder of your own so the tree
shows more than fixtures:

1. **`markscope-light.png`** — light theme, a document open with a few
   headings, the outline rail visible with a section highlighted, and at
   least two roots in the sidebar with some folders expanded. This is the
   one that goes at the top of the README, so it should show the whole app
   doing its actual job.
2. **`markscope-dark.png`** — the same view in dark theme.
3. **`markscope-search.png`** — Quick Open (`Ctrl+F`) with a query typed and
   several results listed.

## Keep in mind

- Whatever is in the tree is public once this is pushed. Use `test-docs/`
  and a folder you are happy to show; check the file names in the sidebar
  and the document content before saving the image.
- PNG, and keep each one under about 500 KB — resize rather than
  screenshotting a 4K display at full resolution.
- Light theme first in the README; a visitor on a light GitHub page reading a
  dark screenshot has to work harder to see what the app is.
