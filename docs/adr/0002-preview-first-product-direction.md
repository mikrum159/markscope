# ADR-0002: Preview-First Product Direction

> Current status: preview-first direction reconfirmed by the user on 2026-09-09. The historical text below is preserved; its later editing phase is not a release commitment.
>
> Source: original MarkScope v2 decision ADR-002, migrated 2026-09-09.

## Status

Accepted

## Context

The product is intended primarily for browsing and reading local Markdown documentation, not editing.

## Decision

Make preview the default mode. Defer editing to a later phase.

## Consequences

Positive:

- Clear product identity.
- Search/navigation get priority.
- Smaller MVP.

Negative:

- Users expecting a Markdown editor must wait for phase 3.
