# MarkScope architecture decisions

The 14 original decisions are split here without changing their numeric identity (ADR-001 is now ADR-0001). Original status is preserved inside each record. The table shows current applicability; migration does not approve the proposed stack or delivery schedule.

ADR-0015 through ADR-0019 were added on 2026-09-13 to record the stack and scope reversals that followed three changes: a Windows-only target, human-driven rather than agent-driven development, and shape-driven development in place of the milestone plan. Superseded records are retained unchanged apart from a pointer to their successor. See [the MVP shape](../plans/mvp-shape/shape.md) for the current working state.

Use [the template](_template.md) for a real new decision; the next app number is 0022. Do not renumber existing decisions. Record supersession explicitly.
